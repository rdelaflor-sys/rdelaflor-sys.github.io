Política de privacidad · Copias elementary

Última actualización: 13 de noviembre de 2026.

Qué hace la aplicación

Copias elementary es una aplicación de uso exclusivamente personal. Usa la API de Google Drive, a través de rclone, para guardar y leer copias de seguridad cifradas y archivos del propio usuario en su propia cuenta de Google Drive.

Datos a los que accede

Solo a los archivos de Google Drive del propietario de la cuenta que la autoriza. No accede a datos de otras personas.

Uso y almacenamiento

Los datos se transfieren solo entre el servidor doméstico del propietario y su Google Drive. No se envían a terceros, no se venden, no se usan para publicidad y no se analizan con ningún otro fin.

Uso de los datos de Google

El uso y la transferencia de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede retirarse en cualquier momento desde myaccount.google.com/permissions.
